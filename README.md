# خامس من الكتاب

تطبيق مستقل للصف الخامس الابتدائي.

- الأسئلة مأخوذة من كتاب الرياضيات وTop Goal 2 فقط.
- لا توجد أسئلة من درس القيمة المنزلية ضمن البلايين.
- أرقام الرياضيات تُعرض بالأرقام العربية الهندية.
- يوجد نطاق مستقل للرياضيات والإنجليزي.
- كل سؤال يعرض اسم الدرس ورقم الصفحة ورقم السؤال الأصلي.
- الإصدار الحالي 0.1.2 هو بداية الفهرسة، وسيتم توسيع بنك الأسئلة من نفس الكتابين فقط.
